## 1. テスト概要

### 1.1 目的
要件定義書に記載されたUI/UX要件、音響・視覚効果、データ永続化、CSV出力、2段階リセット等の機能が、iPhone Safariを含む対象環境で正常に動作することを検証する。

### 1.2 テスト対象環境
- **主対象**: iPhone Safari (iOS 16 / 17 / 18)
- **副対象**: PCブラウザ (Google Chrome, Microsoft Edge, Safari)
- **表示モード**: 通常ブラウザ表示、および「ホーム画面に追加」したスタンドアロンPWAモード
