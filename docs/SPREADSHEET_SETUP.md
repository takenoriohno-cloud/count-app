# Googleスプレッドシート連携 設定・運用ガイド

本ドキュメントでは、チラシ配布カウンターの集計用GoogleスプレッドシートおよびGoogle Apps Script (GAS)の初期セットアップ手順、リアルタイム集計ダッシュボードの構築手順、ならびにイベント終了時の運用方法を解説します。

---

## 1. Googleスプレッドシートの新規作成

1. [Googleスプレッドシート](https://sheets.google.com/) を開き、「新しいスプレッドシートを作成」をクリックします。
2. スプレッドシートのタイトルを任意に設定します（例: `チラシ配布集計管理_2026`）。

---

## 2. Google Apps Script (GAS) のセットアップ

### 2.1 スクリプトエディタを開く
1. メニューバーの **「拡張機能」** > **「Apps Script」** をクリックします。
2. プロジェクト名を「`チラシ配布カウンターAPI`」等に変更します。

### 2.2 スクリプトコードの配置
1. 左側のファイル一覧で `コード.gs` を選択します。
2. エディタ内の既存コードをすべて消去し、リポジトリ内の [`gas/Code.gs`](../gas/Code.gs) の全コードを貼り付けて保存（`Ctrl + S` またはフロッピーアイコン）します。

### 2.3 （推奨）APIトークンの変更
デフォルトでは `counter_secret_token_2026` が設定されています。セキュリティを高める場合は以下のいずれかで変更します：
* **方法A（スクリプトプロパティ）**: 左メニューの「プロジェクトの設定（歯車）」>「スクリプト プロパティを追加」で、プロパティ `API_TOKEN` に任意の英数字キーを設定。
* **方法B（直接書き換え）**: `Code.gs` 内の `DEFAULT_API_TOKEN` を任意文字列に変更。

---

## 3. Webアプリとしてのデプロイ（API公開）

1. 画面右上の青い **「デプロイ」** > **「新しいデプロイ」** をクリックします。
2. 左側の歯車アイコン（種類の選択）をクリックし、**「ウェブアプリ」** を選択します。
3. 以下の通り設定します：
   - **説明**: `チラシ配布カウンター本番API v1`
   - **次のユーザーとして実行**: **「自分」**（スプレッドシートのオーナー）
   - **アクセスできるユーザー**: **「全員」**（※配布スタッフがGoogleログイン不要で送信できるようにするため）
4. **「デプロイ」** をクリックします。
   - ※初回のみ「アクセスを承認」モーダルが表示されます。ご自身のアカウントを選択し、「詳細」>「安全ではないページに移動」をクリックして許可してください。
5. デプロイ完了後に表示される **「ウェブアプリ URL」**（`https://script.google.com/macros/s/.../exec`）をコピーします。

---

### 3.1 スタッフ配布用URLの生成・共有（GitHub公開時の安全運用）

GitHubリポジトリを公開（Public）している場合、本番のGAS URLやトークンをコード（`index.html`）に直接書き込んでコミットすることは**絶対に避けてください**（第三者にスプレッドシートへの書き込み権限が漏洩するため）。

以下の手順で**「接続情報を含んだスタッフ専用リンク」**を生成して共有します：

1. 管理者が自身のブラウザで GitHub Pages（例: `https://<ユーザー名>.github.io/count-app/`）を開きます。
2. ヘッダーの「名前未設定（または名前）」をタップし、設定モーダルを開きます。
3. 「📡 スプレッドシート(GAS)接続設定」を開き、取得した **GAS Web App URL** と **APIトークン** を入力します。
4. **「スタッフ配布用URLをコピー」** ボタンをタップします。
   - クリップボードに以下のような専用URLがコピーされます：  
     `https://<ユーザー名>.github.io/count-app/?gas=https%3A%2F%2Fscript.google.com%2F...&token=...`
5. このURLを、LINEやチャット等でチラシ配りスタッフに共有します。
   - **スタッフ側の体験**: リンクをタップして開くだけで、接続設定が自動で完了します。
   - **セキュリティ**: ページが開いた瞬間にブラウザのアドレスバーからパラメータが自動消去されるため、履歴や誤共有も防げます。

## 4. スプレッドシートのシート構成とダッシュボード構築

### 4.1 生データシート (`raw_logs`)
* 初回送信時に自動生成されますが、手動で事前作成しておくことも可能です。
* **列構成**:
  * **A列**: レコードID（例: `1773223500123-abcde`）
  * **B列**: 記録日時(端末)（例: `2026-10-24T19:05:00.123Z`）
  * **C列**: 端末ID（例: `dev-8f3a-49c1-b0e2-123456789abc`）
  * **D列**: 配布者名（例: `田中`）
  * **E列**: 性別（`男性` / `女性`）
  * **F列**: 年代（`10代` / `20代` / `30代` ...）
  * **G列**: ステータス（`有効` / `取消`）
  * **H列**: 受信日時(サーバー)

---

### 4.2 リアルタイム集計ダッシュボード (`dashboard`)

スプレッドシートの下部「＋」から新しいシートを追加し、名前を `dashboard` に変更します。

#### パターンA: ピボットテーブルによる自動集計（推奨・視覚的）
1. `raw_logs` シート全体を選択し、メニューの **「挿入」** > **「ピボットテーブル」** を選択。
2. 挿入先を `dashboard` シートのセル `A1` に指定。
3. ピボットテーブルのエディタで以下を設定：
   - **行**: `配布者名`（または `端末ID`）
   - **列**: `性別` または `年代`
   - **値**: `レコードID`（集計方法: `COUNTA`）
   - **フィルタ**: `ステータス` を追加し、**「有効」のみにチェック**（「取消」を除外）。

#### パターンB: 関数による「配布者別 × 時間帯別」マトリクス集計
時間帯（1時間単位）で誰が何枚配ったかをマトリクス集計する場合、以下の式を活用できます：

```excel
=QUERY(
  raw_logs!A:H,
  "SELECT D, HOUR(B), COUNT(A) 
   WHERE G = '有効' 
   GROUP BY D, HOUR(B) 
   PIVOT HOUR(B) 
   LABEL D '配布スタッフ'"
)
```
※日時のフォーマットに応じ、スプレッドシート側で `B列` の日時から時間を抽出する計算列（例: `=HOUR(B2)`）を追加するとより直感的に集計可能です。

## 5. イベント終了時の運用（受付停止）

配布イベントが終了し、それ以上の書き込みを防ぎたい場合は以下のいずれかで受付を停止します：

1. **GASの非公開化（推奨）**:
   - Apps Scriptエディタで **「デプロイ」** > **「デプロイを管理」** を開く。
   - 対象デプロイを選択し、右上の鉛筆アイコン（編集）をクリック。
   - 「アクセスできるユーザー」を **「自分のみ」** に変更して保存（アーカイブも可）。
   - これにより、外部端末からの送信は即座に遮断（HTTP 401/403）されます。
2. **シートの保護**:
   - スプレッドシートの `raw_logs` シートを右クリックし、「シートを保護」で編集権限を制限。
