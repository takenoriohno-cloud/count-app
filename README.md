# チラシ配布カウンター (Flyer Distribution Counter)

iPhone Safariでの片手（親指）操作に完全特化した、チラシ配布数カウント用のスタンドアロンWebアプリケーションです。  
ビルドツールやサーバー環境は不要で、単一の `index.html` だけで完全に動作します。

---

## 📱 主な特徴

- **片手（親指）操作への完全特化**
  - 親指の可動域に合わせた画面下半分のマトリクス配置。
  - 横2列（男性・女性）× 縦6行（10代、20代、30代、40代、50代、60代以上）の計12ボタン構成。
  - 画面最下部に大きく目立つ「直前の入力を取り消す（アンドゥ）」ボタンを配置。直前に入力した属性と時刻がリアルタイムに表示されます。
- **触感・音響フィードバック**
  - **Web Audio API**: ボタン押下時に周波数800Hzの短い電子クリック音を発音。
  - **CSSアニメーション**: `:active` 時の押し込みアニメーションおよび瞬間パルス発光エフェクト。
- **リアルタイム集計表示**
  - 画面上部に「総配布枚数」を大きく表示。
  - 年代×性別のクロス集計マトリクス表（各セル数・合計・構成比率）をリアルタイムに更新。
- **データ永続化 & CSVエクスポート**
  - タップごとにタイムスタンプ、性別、年代をJSON配列として `localStorage` に即時保存（再読み込み時も自動復元）。
  - **CSV出力 (BOM付きUTF-8)**: Excelでも文字化けしないBOM付きCSVを生成。
  - **iOS共有シート連携**: `navigator.share`（Web Share API）を優先実行し、AirDropやLINE、メール、ファイル保存へ直接渡せます（非対応環境では自動Blobダウンロード）。
- **誤操作防止の2段階リセット**
  - 誤タップで全データが消えるのを防ぐ、2段階確認モーダルを搭載。

## 🚀 使い方

### 1. ローカルで直接開く
特別な環境構築は不要です。[index.html](file:///c:/Users/user/OneDrive/ドキュメント/Antigravity/count-app/index.html) をお好みのブラウザ（Safari, Chrome, Edge等）にドラッグ＆ドロップして開くだけで動作します。

### 2. iPhone実機で使う（ホーム画面に追加）
1. 本リポジトリのファイルを GitHub Pages、Vercel、Netlify 等にデプロイするか、同一Wi-Fi内のローカルサーバー経由でアクセスします。
2. iPhoneの **Safari** でページを開きます。
3. 画面下部（または上部）の共有アイコンをタップし、**「ホーム画面に追加」** を選択します。
4. ホーム画面から全画面アプリ感覚で起動でき、現場での片手操作が快適に行えます。
