# チラシ配布カウンター (Flyer Distribution Counter)

iPhone Safariでの片手（親指）操作に完全特化した、チラシ配布数カウント用のスタンドアロンWebアプリケーションです。  
ビルドツールやサーバー環境は不要で、単一の `index.html` だけで完全に動作します。

---

## 📱 主な特徴

- **片手（親指）操作への完全特化**
  - 親指の可動域に合わせた画面下半分のマトリクス配置。
  - 横2列（男性・女性）× 縦6行（10代、20代、30代、40代、50代、60代以上）の計12ボタン構成。
  - 画面最下部に大きく目立つ「直前の入力を取り消す（アンドゥ）」ボタンを配置。直前に入力した属性と時刻がリアルタイムに表示されます。
- **Googleスプレッドシート連携 & リアルタイム集計**
  - **15分定期自動送信**: 配布開始中は15分ごとにバックグラウンドで未送信データを自動送信。
  - **手動即時送信**: いつでも未送信バッジ（未送信: ○件）からワンタップで即時送信可能。
  - **端末ID & スタッフネーム管理**: 初回起動時に端末固有UUIDを自動採番し、自由記述の配布者名と紐付けてスプレッドシートへ送信。「いつ、何時の間に、誰が何枚配ったのか」を即座に集計。
  - **配布「開始 / 終了」制御**: 作業中のみタイマーが稼働。終了時には未送信データの自動チェックと最終送信確認を実行。
  - **UNDO取り消し整合性**: 送信済みデータをUNDOした場合も「取消フラグ」を同期し、ダッシュボード集計から自動除外。
- **触感・音響フィードバック**
  - **Web Audio API**: ボタン押下時に周波数800Hzの短い電子クリック音を発音。
  - **CSSアニメーション**: `:active` 時の押し込みアニメーションおよび瞬間パルス発光エフェクト。
- **リアルタイム集計表示**
  - 画面上部に「総配布枚数」を大きく表示。
  - 年代×性別のクロス集計マトリクス表（各セル数・合計・構成比率）をリアルタイムに更新。
- **データ永続化 & CSVエクスポート**
  - タップごとにタイムスタンプ、性別、年代、ステータス、送信フラグを `localStorage` に即時保存。
  - **CSV出力 (BOM付きUTF-8)**: Excelでも文字化けしないBOM付きCSVを生成（送信状況・ステータス列付き）。
  - **iOS共有シート連携**: `navigator.share`（Web Share API）を優先実行し、AirDropやLINE、メール、ファイル保存へ直接共有。
- **誤操作防止の2段階リセット**
  - 誤タップで全データが消えるのを防ぐ、2段階確認モーダルを搭載（取消キューも安全に初期化）。

## 🚀 使い方

### 1. スプレッドシート集計の準備（管理者向け）
配布チーム全体でスプレッドシートに自動集計する場合は、あらかじめGAS Webアプリを公開します。  
詳しい手順は [Googleスプレッドシート設定ガイド](docs/SPREADSHEET_SETUP.md) をご覧ください。

### 2. 配布スタッフの操作手順（現場スタッフ向け）
1. スマホでアプリ（`index.html`）を開きます。
2. ヘッダーの **「名前未設定」** をタップし、ご自身の配布者ネーム（例: `佐藤`）を入力して保存します。
   - ※管理者の指定したGAS WebアプリURLが未入力の場合は、設定画面のアコーディオンから入力します。
3. チラシ配布を開始する際に **「▶ 配布開始」** ボタンをタップします（15分ごとの自動送信が開始されます）。
4. 配布した属性に合わせてマトリクスボタンを親指でタップします。
   - 間違えた場合は最下部の **「UNDO」** ボタンで直ちに取り消せます。
5. 休憩時や配布終了時は **「■ 配布終了」** をタップします。未送信のデータがあれば送信確認メッセージが表示されます。
